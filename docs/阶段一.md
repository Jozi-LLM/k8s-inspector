# K8s-Inspector 代码文档

## 项目概述

K8s-Inspector 是一个基于 Go 语言开发的 Kubernetes 集群自动化巡检工具，用于定期检查集群健康状态、资源使用情况、配置合规性和安全性，并生成结构化巡检报告。该工具采用模块化设计，支持多种检查器和报告格式，具有良好的扩展性。

## 技术架构

### 技术栈
- **语言**: Go 1.25.1
- **K8s客户端**: client-go v0.22.0
- **配置管理**: Viper
- **日志**: Zap
- **YAML处理**: goccy/go-yaml
- **命令行**: 标准库 flag

### 架构模式
项目采用分层架构设计，主要包含以下层次：
1. **入口层** (cmd/): 命令行入口点
2. **分析层** (internal/analyzer/): 巡检引擎
3. **检查层** (internal/checker/): 各类检查器实现
4. **报告层** (internal/reports/): 报告生成器
5. **基础层** (internal/pkg/): 公共组件和工具

## 核心组件详解

### 1. 入口点 (cmd/cli/main.go)

主程序入口，负责：
- 解析命令行参数
- 加载配置文件
- 初始化日志系统
- 根据模式执行巡检或启动服务

支持两种运行模式：
- `inspect`: 单次巡检模式
- `serve`: 服务模式（待实现）

### 2. 分析引擎 (internal/analyzer/engine.go)

巡检核心引擎，主要功能：
- 协调各类检查器的执行
- 计算巡检结果摘要
- 生成健康评分
- 提供改进建议

关键方法：
- `Run()`: 执行完整的巡检流程
- `calculateSummary()`: 计算检查结果统计
- `calculateHealthScore()`: 计算集群健康评分
- `generateRecommendations()`: 生成改进建议

### 3. 检查器系统 (internal/checker/)

采用注册模式管理各类检查器：

#### 注册机制 (registry.go)
- `Register()`: 注册新的检查器
- `Get()`: 获取指定检查器
- `List()`: 列出所有已注册检查器
- `Execute()`: 执行指定检查器

#### 检查器接口 (types.go)
```go
type Checker interface {
    Name() string
    Description() string
    Category() string
    RequiredPermissions() []string
    Execute(ctx context.Context, client *k8s.Client) ([]CheckDetail, error)
}
```

#### 示例检查器 (base/cluster_info.go)
- 检查集群基本信息
- 验证集群连接状态
- 统计节点就绪情况

### 4. 数据类型 (internal/pkg/types/types.go)

定义了核心数据结构：

#### 检查结果
- `CheckDetail`: 单项检查结果详情
- `Summary`: 检查结果统计摘要
- `InspectionResult`: 完整巡检结果

#### 状态定义
- `CheckStatus`: 检查状态 (PASS/WARNING/FAIL/ERROR/SKIPPED)
- `SeverityLevel`: 严重程度 (LOW/MEDIUM/HIGH/CRITICAL)

### 5. 配置管理 (internal/pkg/config/)

使用 Viper 实现灵活的配置管理：

#### 配置结构
- `InspectorConfig`: 巡检相关配置
- `Cluster`: 集群连接配置
- `CheckConfig`: 检查项配置
- `ReportConfig`: 报告输出配置
- `LoggingConfig`: 日志配置
- `AlertingConfig`: 告警配置

#### 配置加载
- `LoadConfig()`: 加载配置文件
- `DefaultConfig()`: 提供默认配置
- `SaveDefaultConfig()`: 保存默认配置到文件

### 6. K8s客户端 (internal/pkg/k8s/client.go)

封装 Kubernetes 客户端操作：
- 支持多种认证方式（kubeconfig/in-cluster）
- 提供集群健康检查
- 获取集群基本信息

### 7. 日志系统 (internal/pkg/utils/logger.go)

基于 Zap 实现结构化日志：
- 支持多种输出格式（JSON/控制台）
- 支持文件轮转
- 提供全局日志实例

### 8. 报告生成器 (internal/reports/)

#### 控制台报告 (console_reporter.go)
- 彩色输出检查结果
- 按类别分组显示
- 提供直观的状态图标

#### JSON报告 (json_reporter.go)
- 结构化数据输出
- 支持时间戳命名
- 便于后续处理和分析

## 配置文件

### 示例配置 (configs/config.yaml)
```yaml
inspector:
  schedule: "0 */6 * * *"
  clusters:
    - name: "default"
      kubeconfig: "$HOME/.kube/config"
      context: ""
  checks:
    enabled:
      - node_health
      - resource_usage
      - pod_health
      - deployment_health
      - security_basic
    thresholds:
      cpu_usage_warning: 80
      memory_usage_warning: 85
      pod_restart_warning: 5
      disk_usage_warning: 90
  reporting:
    formats:
      - console
      - json
    output_dir: "./reports"

logging:
  level: "info"
  format: "console"
  output: "stdout"

alerting:
  slack:
    enabled: false
    webhook: ""
  webhook:
    enabled: false
    url: ""
  email:
    enabled: false
    smtp_server: "smtp.example.com:587"
    recipients: []
```

## 使用方式

### 编译运行
```bash
go build -o k8s-inspector cmd/cli/main.go
./k8s-inspector -config ./configs/config.yaml -mode inspect
```

### 功能特性
1. **模块化检查器**: 易于扩展新的检查项
2. **多种报告格式**: 支持控制台和JSON输出
3. **灵活配置**: 支持YAML配置文件
4. **结构化日志**: 便于问题排查
5. **健康评分**: 提供集群整体健康度评估

## 扩展开发

### 添加新检查器
1. 实现 `Checker` 接口
2. 在 `init()` 函数中注册检查器
3. 在配置文件中添加检查器名称到 `enabled` 列表

### 添加新报告格式
1. 实现 `Reporter` 接口
2. 在 `main.go` 中添加新的报告生成器创建逻辑
